# Terminology Management

## Objective

Consistent terminology is essential for technical documentation.

This repository follows Microsoft terminology whenever possible.

---

## Sources

Terminology is verified using:

- Microsoft Learn
- Azure Portal
- Microsoft product documentation

---

## Translation Rules

### Azure Services

Keep service names in English.

Examples:

- Azure Monitor
- Azure Backup
- Azure Virtual Machines

---

### Azure Resources

Follow Microsoft's Japanese terminology.

Examples:

| English | Japanese |
|----------|----------|
| Resource Group | リソース グループ |
| Virtual Machine | 仮想マシン |
| Storage Account | ストレージ アカウント |

---

### UI Elements

Match Azure Portal labels.

Examples:

- Monitoring
- Alerts
- Access Control (IAM)
- Review + Create

---

## Consistency Review

Every translation is reviewed to ensure that the same term is translated consistently across all projects.
