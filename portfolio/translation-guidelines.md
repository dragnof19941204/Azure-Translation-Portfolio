# Translation Guidelines

## Purpose

The objective of this repository is to create high-quality Japanese technical documentation based on Microsoft Learn.

---

## General Rules

- Preserve technical meaning.
- Do not simplify technical concepts excessively.
- Keep Azure service names in English unless Microsoft provides an official Japanese name.
- Use consistent terminology throughout the repository.

---

## Writing Style

Preferred style:

- Clear
- Professional
- Concise
- Easy to understand

Avoid:

- Literal translation
- Unnatural Japanese
- Ambiguous expressions

---

## Azure Terminology

Follow Microsoft's official terminology whenever possible.

Examples:

| English | Japanese |
|----------|----------|
| Resource Group | リソース グループ |
| Recovery Services vault | Recovery Services コンテナー |
| Azure Monitor | Azure Monitor |
| Log Analytics | Log Analytics |

---

## Markdown Style

Every document should include:

- Overview
- Key Learning Points
- Practical Notes
- Summary

---

## Formatting

Use:

- Markdown headings
- Bullet lists
- Tables when appropriate
- Code blocks when necessary

---

## Repository Consistency

All projects should follow the same directory structure to improve readability and maintenance.
