# Contributing

Thank you for visiting this repository.

This repository is maintained as a personal technical documentation and translation portfolio focused on Microsoft Azure technologies.

## Purpose

The objective of this repository is to demonstrate:

- Azure infrastructure knowledge
- Technical documentation skills
- AI-assisted translation workflow
- Quality assurance process
- Microsoft terminology management

## Translation Process

Each translation follows the workflow below:

1. Review Microsoft Learn documentation
2. Create an AI-assisted draft
3. Verify Microsoft terminology
4. Verify Azure Portal UI terminology
5. Perform technical review
6. Improve Japanese readability
7. Conduct quality assurance
8. Publish to GitHub

## Quality Standards

Every document is reviewed for:

- Technical accuracy
- Microsoft terminology consistency
- Azure Portal UI consistency
- Natural Japanese readability
- Markdown formatting

Suggestions regarding technical accuracy, terminology consistency, or documentation quality are welcome.

Constructive feedback is appreciated and helps improve the overall quality of this portfolio.
