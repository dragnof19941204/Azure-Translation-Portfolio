# Quality Assurance

## Overview

Quality assurance is performed after every translation.

The objective is to ensure that each document is technically accurate, readable, and consistent.

---

## QA Checklist

### Technical Accuracy

- Azure concepts are correct.
- Procedures are complete.
- No technical information is omitted.

---

### Terminology

- Microsoft terminology verified.
- Azure Portal terminology verified.
- Service names consistent.

---

### Language

- Natural Japanese
- Correct grammar
- Appropriate punctuation

---

### Markdown

- Headings
- Tables
- Lists
- Code blocks
- Formatting consistency

---

### Final Review

Before publishing, each document is reviewed one final time.

---

## Continuous Improvement

The repository is continuously updated as Azure documentation evolves.
