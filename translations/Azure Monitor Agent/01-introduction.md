# Introduction

## Overview

Azure Monitor Agent (AMA) is the recommended agent for collecting monitoring data from Azure and hybrid resources.

It replaces older monitoring agents and provides a flexible, centralized configuration model.

## Key Learning Points

- Understand the purpose of Azure Monitor Agent.
- Learn why AMA replaces legacy agents.
- Understand centralized monitoring architecture.
- Learn how AMA integrates with Log Analytics.

## Practical Notes

Azure Monitor Agent simplifies monitoring configuration by separating agent deployment from data collection settings.

## Summary

Azure Monitor Agent provides a modern monitoring platform for Azure environments.
