# Data Collection Rules

## Overview

Data Collection Rules (DCR) define what monitoring data Azure Monitor Agent collects and where the data is sent.

## Key Learning Points

- Configure data sources.
- Select destination workspace.
- Filter collected data.
- Reuse DCR across multiple virtual machines.

## Practical Notes

Using DCR reduces configuration complexity and improves consistency across environments.

## Summary

DCR centralizes monitoring configuration and simplifies operational management.
