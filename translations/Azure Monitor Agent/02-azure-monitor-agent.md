# Azure Monitor Agent

## Overview

Azure Monitor Agent collects performance metrics, event logs, and monitoring data from Azure resources.

## Key Learning Points

- Collect Windows Event Logs
- Collect Linux Syslog
- Collect Performance Counters
- Send monitoring data to Log Analytics

## Practical Notes

Compared with legacy monitoring agents, AMA provides improved scalability and centralized configuration.

## Summary

Azure Monitor Agent is Microsoft's recommended monitoring agent for Azure workloads.
