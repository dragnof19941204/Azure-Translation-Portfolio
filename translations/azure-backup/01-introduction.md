# Introduction

## Overview

Azure Backup is Microsoft's cloud-based backup service designed to protect Azure resources and on-premises workloads.

It enables organizations to secure critical business data while reducing infrastructure management overhead.

---

## Key Learning Points

- Understand the purpose of Azure Backup.
- Learn supported backup scenarios.
- Understand Recovery Services vault.
- Learn how backup improves business continuity.

---

## Practical Notes

Azure Backup is commonly used to protect:

- Azure Virtual Machines
- Azure Files
- SQL Server
- SAP HANA
- On-premises Servers

---

## Summary

Azure Backup provides secure, scalable, and centralized backup management for Azure environments.
