# Backup and Restore

## Overview

Azure Backup supports both backup and recovery operations for protected workloads.

---

## Backup Process

- Select protected resource
- Configure backup policy
- Run backup
- Verify backup status

---

## Restore Process

- Select recovery point
- Choose restore option
- Restore data
- Verify recovery

---

## Practical Notes

Regular restore testing is recommended to ensure recovery procedures function correctly during incidents.

---

## Summary

Successful backup strategies always include periodic recovery testing.
