# Recovery Services Vault

## Overview

Recovery Services vault is the central management component for Azure Backup.

It stores backup metadata, recovery points, and backup policies.

---

## Key Learning Points

- Create a Recovery Services vault.
- Register protected resources.
- Configure backup storage redundancy.
- Manage backup jobs.

---

## Practical Notes

A single Recovery Services vault can protect multiple Azure resources and simplifies backup administration.

---

## Summary

Recovery Services vault centralizes Azure Backup management and improves operational consistency.
