# Action Groups

## Overview

Action Groups define what happens after an alert is triggered.

## Key Learning Points

Supported actions include:

- Email notifications
- SMS notifications
- Push notifications
- Voice calls
- Azure Functions
- Logic Apps
- Webhooks

## Practical Notes

Action Groups centralize notification settings and can be reused across multiple Alert Rules.

## Summary

Using Action Groups improves operational efficiency by standardizing alert notifications and automated responses.
