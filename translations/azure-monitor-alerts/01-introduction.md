# Introduction

## Overview

Azure Monitor Alerts is a monitoring feature that automatically detects issues based on metrics, logs, and activity events. When configured conditions are met, Azure Monitor generates alerts and can notify administrators or trigger automated actions.

## Key Learning Points

- Understand the purpose of Azure Monitor Alerts.
- Learn how alerts help detect issues proactively.
- Identify different alert types supported by Azure Monitor.
- Understand how alerts integrate with Action Groups.

## Summary

Azure Monitor Alerts helps administrators monitor Azure resources continuously and respond quickly to unexpected conditions through notifications and automation.
