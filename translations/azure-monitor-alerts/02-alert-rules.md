# Alert Rules

## Overview

Alert Rules define the conditions that Azure Monitor evaluates to determine whether an alert should be triggered.

## Key Learning Points

- Alert rules monitor metrics, logs, and activity events.
- Conditions define when alerts are generated.
- Severity levels help prioritize incidents.
- Scope determines which Azure resources are monitored.

## Practical Notes

Typical alert examples include:

- Virtual Machine CPU utilization
- Memory utilization
- Azure Storage availability
- Azure SQL DTU utilization
- ExpressRoute connection status

## Summary

Alert Rules are the foundation of Azure Monitor and allow proactive monitoring based on predefined conditions.
