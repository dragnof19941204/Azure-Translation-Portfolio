# Configure Log Analytics Health Status Alerts

## Japanese Translation

Azure Service Health は、Log Analytics ワークスペースを含む Azure リソースの正常性を監視します。

正常性ステータスアラートを構成することで、ワークスペースの状態変化を通知できます。

## Important Terms

| English | Japanese |
|---|---|
| Health status | 正常性ステータス |
| Resource Health | リソースの正常性 |
| Alert rule | アラートルール |
| Action group | アクショングループ |
