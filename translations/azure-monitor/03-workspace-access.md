# Configure Log Analytics Workspace Access

## Japanese Translation

Log Analytics ワークスペースでアクセスできるデータは、以下の要素によって決定されます。

- ワークスペース自体の設定
- ワークスペースへデータを送信するリソースへのアクセス権
- ワークスペースへのアクセス方法

## Access Modes

### Workspace Context

ワークスペース内で権限を持つすべてのログを表示できます。

### Resource Context

特定のリソースに関連するログのみ表示できます。

## RBAC Roles

| Role | Description |
|---|---|
| Log Analytics Reader | 監視データの参照 |
| Log Analytics Contributor | 監視設定の変更 |
