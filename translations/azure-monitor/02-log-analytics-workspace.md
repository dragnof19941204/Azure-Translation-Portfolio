# Create a Log Analytics Workspace

## Japanese Translation

Azure Monitor Logs は、監視対象リソースからログデータやパフォーマンスデータを収集・整理する Azure Monitor の機能です。

Log Analytics ワークスペースは、Azure Monitor やその他の Azure サービスから収集されたログデータを保存するための専用環境です。

ワークスペースには独自のデータリポジトリと構成がありますが、複数のサービスから収集したデータを統合できます。

## Translation Notes

- Log Analytics workspace → Log Analytics ワークスペース
- Workspace ID → ワークスペース ID
- Resource ID → リソース ID
- Query → クエリ
