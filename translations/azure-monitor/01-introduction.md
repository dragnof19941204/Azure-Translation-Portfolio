# Azure Monitor - Introduction

## Original Module

Microsoft Learn  
Deploy and configure Azure Monitor

## Overview

Azure Monitor collects log data and stores it in tables. Administrators use Log Analytics in the Azure portal to configure input data sources and run queries against Azure Monitor logs.

## Japanese Translation

Azure Monitor はログデータを収集し、テーブルに保存します。

管理者は Azure portal の Log Analytics を使用して、入力データソースを構成し、Azure Monitor ログに対するクエリを実行します。

あなたは Tailwind Traders の IT 運用部門に所属しています。Azure ワークロードを支える監視インフラストラクチャが適切に構成されていることを確認する責任があります。

Log Analytics ワークスペースについて、適切なユーザーのみがアクセスできるように構成し、適切なデータ保持期間を設定する必要があります。また、ワークスペースの正常性が低下した場合に通知を受け取れるようにする必要があります。

## Learning Objectives

このモジュールでは、以下について学習します。

- Log Analytics ワークスペースを作成する
- Log Analytics ワークスペースへのアクセスを構成する
- Log Analytics ワークスペースのデータ保持を構成する
- Log Analytics ワークスペースの正常性ステータスアラートを有効にする
