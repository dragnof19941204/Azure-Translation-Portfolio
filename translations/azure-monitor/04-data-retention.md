# Configure Log Analytics Data Retention

## Japanese Translation

保持ポリシーは、Log Analytics ワークスペース内のデータをいつ削除またはアーカイブするかを定義します。

アーカイブを使用すると、使用頻度の低い古いデータを低コストで保持できます。

## Important Terms

| English | Japanese |
|---|---|
| Retention policy | 保持ポリシー |
| Archive | アーカイブ |
| Interactive retention | 対話型保持期間 |
| Purge | パージ |
