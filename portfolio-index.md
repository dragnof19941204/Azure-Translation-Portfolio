## Translation Workflow

Every project follows the same workflow.

1. Read Microsoft Learn documentation
2. Create AI-assisted translation draft
3. Verify Microsoft terminology
4. Verify Azure Portal UI terminology
5. Perform technical review
6. Improve Japanese readability
7. Final quality assurance
8. Publish to GitHub

---

## Quality Standards

Each translation is reviewed for:

- Microsoft official terminology
- Azure Portal UI consistency
- Technical accuracy
- Natural Japanese readability
- Formatting consistency
